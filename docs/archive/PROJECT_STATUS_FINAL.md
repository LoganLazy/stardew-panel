## 🚀 部署方式

### 1. Docker 部署 ⭐⭐⭐⭐⭐
```bash
cd docker
docker-compose up -d --build
```
- ✅ 一键部署
- ✅ 环境隔离
- ✅ 推荐生产环境

### 2. 本地开发 ⭐⭐⭐⭐
```bash
# 后端
cd server && go run main.go

# 前端
cd web && npm run dev
```
- ✅ 热重载
- ✅ 推荐开发环境

### 3. 二进制部署 ⭐⭐⭐
```bash
cd web && npm run build
cd server && go build -o stardew-panel
```
- ✅ 性能最佳
- ⚠️ 需手动构建
