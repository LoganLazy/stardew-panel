## 🚀 部署方式

### Docker（推荐）⭐⭐⭐⭐⭐
```bash
cd docker
docker-compose up -d --build
# 访问 http://localhost:8080
```

### 本地开发 ⭐⭐⭐⭐
```bash
cd server && go run main.go
cd web && npm run dev
# 访问 http://localhost:5173
```

### 二进制 ⭐⭐⭐
```bash
cd web && npm run build
cd server && go build
./stardew-panel
```
