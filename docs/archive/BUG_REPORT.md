### 2. 🔴 潜在 Bug

#### 2.1 日志文件路径硬编码
```go
// server/service/player.go:41
logPath := "./data/server.log"
```
**问题**: 
- 如果游戏日志不在这个位置会失败
- 没有从配置文件读取

**建议**: 
```go
logPath := filepath.Join(cfg.Game.ServerPath, "server.log")
```

---

#### 2.2 日志解析正则表达式可能不匹配
```go
joinPattern := regexp.MustCompile(`(\w+) joined the game`)
leftPattern := regexp.MustCompile(`(\w+) left the game`)
```
**问题**: 
- 不同版本游戏日志格式可能不同
- 中文玩家名可能无法匹配（\w 只匹配字母数字）

**建议**: 
```go
joinPattern := regexp.MustCompile(`(.+?) joined the game`)
leftPattern := regexp.MustCompile(`(.+?) left the game`)
```

---

#### 2.3 SteamCMD 路径查找可能失败
```go
// server/service/install.go
func (s *InstallService) findSteamCMD() string
```
**问题**: 
- 只检查常见路径
- Windows/Linux/Mac 路径不同
- 可能找不到

**建议**: 
- 允许用户在配置文件指定路径
- 提供明确的安装指引

---

#### 2.4 密码在错误日志中可能泄露
```go
// server/service/install.go:164
return fmt.Errorf("SteamCMD 执行失败: %w\n%s", err, string(output))
```
**问题**: 
- SteamCMD 输出可能包含密码
- 错误信息会返回给前端

**建议**: 
```go
// 过滤敏感信息
output = strings.ReplaceAll(output, password, "****")
```

---

#### 2.5 并发问题：多个操作同时进行
**场景**: 
- 用户同时点击"启动服务器"和"上传MOD"
- 可能导致文件冲突

**建议**: 
- 添加操作锁
- 或在前端禁用同时操作

---

### 3. ⚠️ 安全性问题

#### 3.1 文件上传无大小限制
```go
// handler/mod.go:35
file, err := c.FormFile("file")
```
**问题**: 
- 可能上传超大文件导致服务器卡死
- 占满磁盘空间

**建议**: 
```go
c.Request.Body = http.MaxBytesReader(c.Writer, c.Request.Body, 500*1024*1024) // 500MB
```

---

#### 3.2 路径注入风险
```go
// service/install.go
// 用户输入的路径未充分验证
```
**问题**: 
- 用户可能输入 `../../etc/passwd`
- 删除重要文件

**建议**: 
```go
// 验证路径是否合法
if strings.Contains(path, "..") {
    return errors.New("非法路径")
}
```

---

#### 3.3 命令注入风险
```go
exec.Command(steamcmdPath, "+login", username, password, ...)
```
**问题**: 
- 如果用户名/密码包含特殊字符可能注入命令

**建议**: 
- 验证输入格式
- 使用参数化命令（已经在用，相对安全）

### 5. 🟢 性能问题

#### 5.1 日志文件可能很大
```go
// 读取整个日志文件
scanner := bufio.NewScanner(file)
for scanner.Scan() { ... }
```
**问题**: 
- 日志文件几百 MB 时会很慢
- 占用大量内存

**建议**: 
```go
// 只读取最后 N 行
tail -n 1000 server.log
```

---

#### 5.2 前端轮询频率过高
```javascript
// 每 3 秒刷新日志
setInterval(loadLogs, 3000)
```
**问题**: 
- 增加服务器负载
- 浪费带宽

**建议**: 
- 改为 5-10 秒
- 或使用 WebSocket
