## 🚀 部署方式

### 1. Docker（推荐生产）⭐⭐⭐⭐⭐
```bash
cd docker
docker-compose up -d --build
# 访问 http://localhost:8080
```

### 2. 本地开发 ⭐⭐⭐⭐
```bash
# 后端
cd server && go run main.go

# 前端
cd web && npm run dev
# 访问 http://localhost:5173
```

### 3. 二进制部署 ⭐⭐⭐
```bash
# 构建
cd web && npm run build
cd ../server && go build

# 运行
./stardew-panel
```
